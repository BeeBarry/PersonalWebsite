Toolstations

Portfolio-projekt · 2026

Toolstations är en hierarkisk utforskare med fyra nivåer: Realm → Area → Category → Item. Tanken är att en utvecklare snabbt ska hitta verktyg och resurser strukturerade efter teknikdomän — utan att behöva googla samma frågor om och om igen.

✅ React + TypeScript frontend med routing per nivå
✅ .NET-backend med Entity Framework Core mot PostgreSQL
✅ Driftat på Azure Container Apps med Docker
✅ CI/CD via GitHub Actions
✅ Sökning och filtrering på alla nivåer
✅ Auth-skyddad admin-panel för CRUD

Den största lärdomen var att hierarkisk navigering är klurigare än man tror — URL-strukturen, brödsmulor och back-navigation måste fungera tillsammans utan att kännas tungrott.

React, TypeScript, .NET, EF Core, PostgreSQL, Azure Container Apps

Barrynamdari.se

Portfolio-projekt · 2026

Den här sajten är min hub för portfolio och fältnoteringar — alltihop byggt statiskt med Astro 6 för snabb laddningstid och bra SEO.

✅ Astro 6 + Content Layer med markdown/MDX-baserade collections för projekt och posts
✅ View Transitions för SPA-känsla utan client-side routing
✅ Astro 6 Fonts API med Schibsted Grotesk + Spline Sans Mono (auto-preload, subsetting)
✅ Tailwind v4 med CSS-först-tokens och @theme inline för tema-växling
✅ Mörkt/ljust tema med persistens via localStorage och astro:after-swap
✅ Sheet-drawer för projektdetaljer + IntersectionObserver-reveals
✅ Responsivt: <560px döljer nav, <640px ger bottom-sheet, <720px stackar hero

Lärdomen: en personlig sajt är värd att finslipa. Den får vara den första stora portföljbiten i sig själv.

Astro 6, TypeScript, Tailwind v4, MDX
